# Pac-Man

## ゲーム内容

SDL2を使用して制作した、パックマン風の迷路アクションゲームです。

プレイヤーが迷路内のドットを集めながら、追跡してくる敵を避けるゲームを制作しました。

## 実装した機能

- 2次元配列を利用した迷路管理
- BFS（幅優先探索）による敵の追跡AI
- スコアと残機の管理
- ステージ切り替え
- キャラクターアニメーション
- 効果音の再生

## 制作で工夫したところ

特に工夫したのは、敵キャラクターの追跡AIです。
単純にプレイヤーの方向へ移動するのではなく、BFS（幅優先探索）を使用して迷路内の経路を探索する仕組みを実装しました。
探索した経路を逆にたどることで、壁を考慮しながらプレイヤーへ近づく移動処理を実現しました。

## 制作を通して学んだこと

今回の制作を通して、探索アルゴリズムを実際のゲームAIに応用する方法を学びました。
また、2次元配列を用いたマップ管理や、ゲームの状態に応じた処理の切り替えなど、ゲーム開発の基礎となる仕組みへの理解を深めました。
